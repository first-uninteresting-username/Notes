# Oda do młodości

Utwór stanowi pomost pomiędzy epokami.
Wykorzystuję klasyczną formę gatunku ludzkiego, ale niesie treść romantyczną

|                                                    | Młodzi                                     | Starzy                   |
| -------------------------------------------------- | ------------------------------------------ | ------------------------ |
| Przestrzeń w której się sytuują                    | Przestworza                                | Ziemia, "Martwy świat"   |
| Perspektywa na świat                               | Szeroka, wysoka                            | Brak perspektywy         |
| Barwy i zjawiska, które towarzyszą obrazowi świata | Barwy jasne                                | Barwy ciemne, szare      |
| Postawy, które przyjmują                           | Otwartość, gotowość do działania, przyjaźń | Samolubność, zamkniętość |

"Oda" jest wezwaniem.
