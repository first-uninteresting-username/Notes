# Rodzina jako podstawowa grupa społeczna

Niektóre funkcje rodziny:

- Emocjonalna
- Ekonomiczna
- Wychowcza

Rodzaje rodziny:

- Mała (nuklearna)
- Duża (wielopokoleniowa)

Podział rodziny ze względu na formalność

Rodzaje małżeństwa:

- Monogamiczne
- Poligamiczne

Model patiarchalny i partnerski, model matiarchalny prawie nie występuje

Pojęcia:

- Adopcja (Przysposobienie)
- Alimenty
